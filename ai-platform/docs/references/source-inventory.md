## Enterprise comparison

- **Reference:** [Solo Enterprise for agentgateway overview](https://docs.solo.io/agentgateway/kubernetes/latest/documentation/about/overview/), which resolved from the supplied “latest” URL during inspection.
- **Classification:** Commercial, optional Enterprise product; not an OSS code dependency.
- **Evidence inspected:** The overview's OSS-versus-Enterprise table identifies `EnterpriseAgentgatewayBudget` spend budgets as Enterprise-only. The lab source also distinguishes `promptGuard` from the Enterprise `entPromptGuard`/Purview extension.
- **Implication:** The MVP proposal targets agentgateway OSS `v1.6.0`. It excludes Enterprise budget enforcement, Purview, and Enterprise-only management UI behavior. Reconsider only through an explicit later scope decision.

- No commitment is made here that the platform's present translator output matches the pinned OSS schema.
- No external lab test was executed. The referenced Rego/Rust/Python test sources are evidence of authored checks only, not passing results.
